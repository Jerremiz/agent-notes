<p class="lead">正文里反复出现几种标记和折叠块，先认一遍，读的时候就不用停下来猜。</p>

<div class="legend">
  <div><h4>先读这页</h4><p>“怎么学”和“本质地图”是全书骨架。每章开头标着它 <span class="qchip">回答</span> 哪几个问题，点击即可回到地图里对应位置。</p></div>
  <div><h4>三层深度</h4><p>每章的小节标了 <span class="lv l1">基础</span> <span class="lv l2">进阶</span> <span class="lv l3">深入</span>。第一遍只看基础，第二遍补进阶，深入部分对着源码读。</p></div>
  <div class="wide"><h4>名词卡</h4><p>每个关键名词第一次出现时有一张可展开的 <b style="color:var(--r-system)">词</b> 卡。先看“本质”一行：它属于哪个问题、方案在哪一层；下面是它的来历和现状。状态分为：</p><p class="marks"><span class="st hot">正流行</span> <span class="st infra">已成标配</span> <span class="st absorbed">已练进模型</span> <span class="st stable">稳定</span> <span class="st debate">仍在演变</span> <span class="st gone">已淘汰</span></p></div>
  <div><h4>pi 的做法</h4><p>对照 pi 源码的区块默认折叠，只显示一行结论。源码有效时间短，需要时再展开。文中的路径对应 pi 的 <a href="https://github.com/earendil-works/pi/releases/tag/v1.4.0" target="_blank" rel="noopener"><code>v1.4.0</code></a>，源码地图在<a href="#px">附录</a>。</p></div>
  <div><h4>先答再看</h4><p>每章末尾的问答默认折叠。先自己讲一遍，再展开对照要点和“再深一步”。</p></div>
  <div class="wide"><h4>前瞻</h4><p>每章末尾的紫色 <b style="color:var(--r-system)">前瞻</b> 框把“现在是什么样”和“接下来会怎么变”分开标注：</p><ul class="marks-list"><li><span class="cf sure">现状</span>现在就是这样，有一手资料或多家产品实践支持（不代表它会一直成立）</li><li><span class="cf likely">推测</span>根据现有迹象判断接下来会怎么变</li><li><span class="cf open">有争议</span>业内仍有分歧，或证据还不够</li></ul></div>
</div>
